Práctica 4
El programa al inciar crea o trata de leer un archivo.ser con las preguntas base del juego.
En el método privado se encuentran las preguntas por si se requiere algún cambio

Posteriormente se hacen las preguntas y dependiendo de la respuesta afirmativa o positiva se llega a una de las hojas y en caso de adivinar el deporte se muestra un mensaje de felicitación y se termina el programa.

En caso contrario se pregunta algo nuevo para agregar al árbol y se guardan los datos, se repite el ciclo hasta llegar a las 20 preguntas o adivinar el juego.
